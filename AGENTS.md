# Crooked Galaxy repository instructions

## Visual asset authorization

The project owner authorizes Codex to generate, draw, edit, transform, retouch,
crop, resize, recolor, composite, optimize and integrate visual assets for this
project. This authorization includes user-supplied candidates, internal reference
placeholders and Codex-created derivatives.

Codex may:

- inventory and specify required assets;
- prepare code-native or raster placeholders and procedural fallbacks;
- define filenames, dimensions, anchors, masks, budgets and import contracts;
- correct technical or visual defects in supplied assets;
- create derived states, responsive variants and optimized runtime exports;
- integrate assets after documenting their source and intended replacement status.

Visual work must still follow the project identity, preserve source files when a
destructive change would remove useful material, and be validated in the target UI.

## Mandatory visual-asset quality gate

Before creating, altering or integrating a raster asset, read
`Notes/ASSET_GENERATION_RULES.md` completely and follow its intake gate.

- Inspect at least three relevant local references and one current in-game capture or production asset.
- Record the concrete traits to preserve and reject; style labels alone are not evidence.
- Review candidates individually or in a clearly identified batch and treat them as unapproved until validated.
- Preserve an original or reproducible source before destructive changes.
- A direct request to process a named folder, archive or reviewed batch is sufficient integration authority; repeated approval of every exact filename is not required.
- Validate approved files at the intended 450×800 Android presentation size and against the rejection checklist.
- Reject major visual or technical mismatches even when the source file is polished.

Existing reference assets may be consulted locally and used as documented internal
placeholders. Reference-derived material must remain labelled so it can be replaced
before a genuinely public commercial release when ownership or licensing is not
confirmed.
